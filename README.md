PotatoBooster is a lightweight C# WPF app built to boost low-end PC performance.

    Game Boost: Forces High CPU/IO priority, maximum core affinity, and RAM trimming.

    System Tweaks: Enables Ultimate Power Plan, unparks CPUs, and disables telemetry.

    Cleaner & Network: Clears temp/GPU caches, flushes DNS, and disables Nagle's algorithm.
