# PotatoBooster 🚀

PotatoBooster is an open-source WPF application designed to optimize low-end Windows PCs for gaming. It automates system tweaks, frees up memory, and prioritizes game processes in a single click.

## Features

* **Game Optimization:** Applies High CPU/IO priority, maximum core affinity, and low TCP latency to selected games.
* **Memory & Storage:** Trims background process working sets and purges temporary files along with GPU shader caches.
* **System Tweaks:** Sets the Ultimate High Performance power plan, unparks CPU cores, and disables Windows telemetry.
* **Auto-Update & Persistence:** Built-in release check on startup and automatic JSON config saving.

## Requirements

* Windows 10/11 (64-bit)
* Administrator privileges (required for system-level tweaks)

## Usage

1. Download the latest `PotatoBooster.exe` from Releases.
2. Right-click and **Run as Administrator**.
3. Select your active game process and click **Boost All**.
